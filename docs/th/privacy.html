นโยบายความเป็นส่วนตัว

MyFi (iOS) · อัปเดตล่าสุด: 16 ตุลาคม 2569

สรุปโดยย่อ

MyFi ไม่เก็บรวบรวม ไม่ส่ง และไม่ขายข้อมูลส่วนบุคคลใดๆ แอปนี้ไม่มีเซิร์ฟเวอร์ ชื่อ Wi-Fi รหัสผ่าน รูปภาพ และตำแหน่งที่ตั้ง จะถูกประมวลผลและจัดเก็บบนอุปกรณ์ของคุณเท่านั้น MyFi ไม่ใช้โฆษณา เครื่องมือวิเคราะห์ของบุคคลที่สาม หรือเครื่องมือติดตามใดๆ (ไม่มี SDK, คุกกี้ หรือตัวระบุเพื่อการโฆษณา) และไม่ต้องสมัครสมาชิกหรือเข้าสู่ระบบ เพื่อให้ทราบจำนวนผู้ใช้และแก้ไขข้อผิดพลาด แอปจะส่งเพียงสถิติการใช้งานแบบไม่ระบุตัวตนและรายงานข้อขัดข้องเท่านั้น (ดูข้อ 3)

1. สิทธิ์ที่แอปใช้

กล้อง ไม่บังคับ

ใช้เพื่อถ่ายรูปป้าย Wi-Fi และรู้จำชื่อเครือข่าย (SSID) กับรหัสผ่านด้วยการรู้จำข้อความ (OCR) รูปภาพจะถูกวิเคราะห์ด้วยเฟรมเวิร์ก Vision ของ Apple บนอุปกรณ์ของคุณทั้งหมด รูปภาพและผลการรู้จำจะไม่ถูกส่งไปที่ใดเลย รูปภาพใช้เพื่อการรู้จำเท่านั้นและแอปจะไม่เก็บไว้

รูปภาพ ไม่บังคับ

ใช้เมื่อคุณเลือกรูปป้าย Wi-Fi จากคลังรูปภาพ หรือเลือกโลโก้ร้านเพื่อใส่ในป้าย แอปเข้าถึงได้เฉพาะรูปที่คุณเลือกเท่านั้น ไม่อ่านคลังรูปภาพทั้งหมด และไม่ส่งรูปภาพใดๆ ออกไปเลย

ตำแหน่งที่ตั้ง ไม่บังคับ

ใช้เพื่อวัตถุประสงค์สองประการเท่านั้น:

  • iOS กำหนดให้แอปต้องได้รับสิทธิ์ตำแหน่งที่ตั้งจึงจะอ่านชื่อ (SSID) ของเครือข่าย Wi-Fi ที่คุณเชื่อมต่ออยู่ได้ ซึ่งเป็นนโยบายของ Apple
  • MyFi จะจำสถานที่ที่คุณเชื่อมต่อหรือแชร์เครือข่าย เพื่อให้เครือข่ายนั้นขึ้นไปอยู่บนสุดของรายการเมื่อคุณกลับไปที่เดิม (และแสดงบนแผนที่)

แอปจะตรวจสอบตำแหน่งที่ตั้งเฉพาะขณะที่คุณใช้งานแอปอยู่เท่านั้น ไม่มีการติดตามในเบื้องหลังและไม่มีการบันทึกเส้นทาง พิกัดจะถูกจัดเก็บไว้บนอุปกรณ์ของคุณพร้อมกับรายการ Wi-Fi เท่านั้น และจะไม่ถูกส่งไปที่ใดเลย

สิทธิ์ทั้งหมดนี้เป็นทางเลือก หากคุณปฏิเสธ คุณสมบัติส่วนใหญ่ เช่น การสร้างคิวอาร์โค้ดและป้าย ยังคงใช้งานได้ตามปกติ จะใช้ไม่ได้เฉพาะคุณสมบัติที่ต้องใช้สิทธิ์นั้นเท่านั้น คุณเปลี่ยนสิทธิ์ได้ทุกเมื่อใน iOS ที่ การตั้งค่า → MyFi

2. ข้อมูลที่จัดเก็บบนอุปกรณ์

ข้อมูลต่อไปนี้จัดเก็บไว้บนอุปกรณ์ของคุณเท่านั้น และเป็นข้อมูลที่คุณป้อนหรือบันทึกเองทั้งหมด

  • ชื่อ Wi-Fi (SSID) และรหัสผ่าน — เครือข่ายที่คุณบันทึก เชื่อมต่อ หรือแชร์
  • เวลาและสถานที่ที่บันทึก — สำหรับการแนะนำเครือข่ายใกล้เคียงและแผนที่ (หากคุณอนุญาตให้เข้าถึงตำแหน่งที่ตั้ง)
  • การตั้งค่าป้าย — ชื่อร้าน ข้อความ ธีมและเลย์เอาต์ที่เลือก รูปโลโก้
  • ชื่อ Wi-Fi ที่คุณแจ้งให้แอปทราบ — ชื่อที่นำเข้าจากภาพหน้าจอของการตั้งค่าหรือพิมพ์เอง (ไม่รวมรหัสผ่าน)

ข้อมูลจัดเก็บไว้ในพื้นที่จัดเก็บภายในของ iOS (UserDefaults) และเพื่อให้วิดเจ็ตบนหน้าจอโฮมแสดงรายการเดียวกันได้ แอปและวิดเจ็ตยังใช้พื้นที่จัดเก็บ App Group ร่วมกันด้วย (group.com.leeo.wifisnap) พื้นที่นี้อยู่บนอุปกรณ์ของคุณ และแอปอื่นไม่สามารถเข้าถึงได้

หมายเหตุ: ข้อมูลนี้อาจรวมอยู่ในข้อมูลสำรองของอุปกรณ์ (การสำรองข้อมูล iCloud หรือการสำรองข้อมูลผ่าน Finder หรือ iTunes) การสำรองข้อมูลเป็นคุณสมบัติของ Apple ซึ่งอยู่ภายใต้นโยบายความเป็นส่วนตัวของ Apple และนักพัฒนาไม่สามารถเข้าถึงเนื้อหาในข้อมูลสำรองได้

3. บุคคลที่สามและการสื่อสารผ่านเครือข่าย

MyFi ไม่มีเซิร์ฟเวอร์ของตัวเอง และไม่ส่งข้อมูล Wi-Fi รูปภาพ หรือตำแหน่งที่ตั้งไปยังนักพัฒนาหรือบุคคลที่สามใดๆ แอปไม่มี SDK สำหรับการวิเคราะห์ โฆษณา หรือรายงานข้อขัดข้องของบุคคลที่สาม

สถิติการใช้งานแบบไม่ระบุตัวตน

เพื่อให้ทราบจำนวนผู้ใช้และแก้ไขข้อผิดพลาด MyFi จะส่งสถิติแบบไม่ระบุตัวตนต่อไปนี้ ไปยัง Apple iCloud (CloudKit) ซึ่งมีเพียงนักพัฒนาเท่านั้นที่ดูได้

  • ID แบบสุ่มที่สร้างขึ้นเมื่อติดตั้ง (ไม่เชื่อมโยงกับตัวคุณ Apple ID อุปกรณ์ หรือแอปอื่น และจะเปลี่ยนไปเมื่อติดตั้งใหม่)
  • เวอร์ชันของแอป เวอร์ชันของ iOS การตั้งค่าภูมิภาคและภาษา
  • จำนวนครั้งและวันที่เปิดแอป วันที่ติดตั้ง และจำนวนวันนับตั้งแต่ติดตั้ง
  • รายงานเมื่อแอปค้างหรือปิดตัวโดยไม่คาดคิด (เวอร์ชันของแอป เวอร์ชันของ iOS รุ่นอุปกรณ์ รายละเอียดทางเทคนิคของข้อผิดพลาด)

สถิติเหล่านี้ไม่มีสิ่งที่คุณสร้างขึ้นเลย เช่น ชื่อ รายชื่อติดต่อ ตำแหน่งที่ตั้ง ชื่อหรือรหัสผ่าน Wi-Fi หรือรูปภาพ และจะส่งเฉพาะเมื่อคุณลงชื่อเข้าใช้ iCloud อยู่เท่านั้น สถิติถูกส่งโดยไลบรารีกลางที่นักพัฒนาเขียนขึ้นเอง (LeeoKit) และจะไม่ถูกส่งต่อให้บุคคลที่สามใดๆ

รูปคิวอาร์โค้ดและรูปป้ายที่คุณสร้างจะถูกส่งต่อเฉพาะเมื่อคุณแตะปุ่มแชร์หรือปุ่มพิมพ์เท่านั้น โดยส่งผ่านแผ่นงานแชร์มาตรฐานของ iOS ไปยังบุคคล แอป หรือเครื่องพิมพ์ที่คุณเลือก จะส่งไปที่ใดขึ้นอยู่กับคุณทั้งหมด

4. การเก็บรักษาและการลบข้อมูล

ข้อมูลที่บันทึกไว้จะอยู่บนอุปกรณ์ของคุณจนกว่าคุณจะลบ โดยลบได้ดังนี้:

  • Wi-Fi ที่บันทึกไว้ — แตะเครือข่ายในรายการค้างไว้ แล้วแตะ "ลบ"
  • ป้าย — ลบออกจากรายการป้าย
  • ข้อมูลทั้งหมด — เมื่อลบแอป ข้อมูลที่เกี่ยวข้องทั้งหมดบนอุปกรณ์ รวมถึงพื้นที่ที่ใช้ร่วมกับวิดเจ็ต จะถูกลบออกไปด้วย

เนื่องจากนักพัฒนาไม่ได้เก็บข้อมูลส่วนบุคคลใดๆ จึงไม่มีขั้นตอนการขอลบข้อมูลแยกต่างหาก สถิติการใช้งานแบบไม่ระบุตัวตนไม่ได้เชื่อมโยงกับตัวคุณ จึงไม่สามารถแยกข้อมูลของบุคคลใดออกมาได้ และการติดตั้งแอปใหม่จะสร้าง ID แบบสุ่มใหม่

5. ความเป็นส่วนตัวของเด็ก

MyFi ไม่ได้มุ่งเป้าไปที่เด็ก และไม่เก็บรวบรวมข้อมูลส่วนบุคคลจากผู้ใดเลยไม่ว่าจะอายุเท่าใด สถิติการใช้งานแบบไม่ระบุตัวตนไม่สามารถสืบย้อนไปถึงบุคคลใดได้

6. ความปลอดภัย

ข้อมูล Wi-Fi ไม่เคยออกจากอุปกรณ์ของคุณ จึงไม่อาจรั่วไหลระหว่างการส่งข้อมูลได้ ปัจจุบันรหัสผ่าน Wi-Fi ถูกจัดเก็บไว้ในพื้นที่จัดเก็บภายในของ iOS (UserDefaults) และได้รับการปกป้องด้วยการล็อคอุปกรณ์ (รหัสหรือ Face ID) และแซนด์บ็อกซ์ของแอปใน iOS หากคุณใช้อุปกรณ์ร่วมกับผู้อื่นหรือทำงานในสภาพแวดล้อมที่ต้องระวังเป็นพิเศษ เราแนะนำให้ป้อนรหัสผ่านเมื่อต้องการใช้แทนการบันทึกไว้

7. การเปลี่ยนแปลงนโยบายนี้

หากนโยบายนี้มีการเปลี่ยนแปลง เราจะอัปเดตหน้านี้และวันที่ "อัปเดตล่าสุด" ที่ด้านบน สำหรับการเปลี่ยนแปลงที่สำคัญ เช่น การเก็บข้อมูลประเภทใหม่ เราจะแจ้งไว้ในรายละเอียดการอัปเดตของแอปด้วย
