แชร์และเชื่อมต่อ Wi-Fi ได้ง่ายๆ

ไม่ต้องสะกดรหัสผ่านทีละตัวอีกต่อไป คิวอาร์โค้ดเดียวก็เรียบร้อย

ดูคุณสมบัติ GitHub

iOS 17.0 ขึ้นไป · iPhone

สร้างมาเพื่อสถานการณ์แบบนี้

คุณบอกรหัส Wi-Fi ให้แขกฟัง แต่เขากลับพิมพ์ผิด คุณจดรหัสผ่านจากป้ายบนผนังร้านกาแฟ แต่ผิดไปหนึ่งตัว คุณต้องอธิบายรหัสผ่านเดิมซ้ำแล้วซ้ำเล่า MyFi เปลี่ยนเรื่องทั้งหมดนี้ให้เหลือแค่คิวอาร์โค้ดเดียวและรูปถ่ายเพียงรูปเดียว

คุณสมบัติ

🔗

แชร์ Wi-Fi ด้วยคิวอาร์โค้ด

MyFi ตรวจหาชื่อเครือข่ายที่คุณเชื่อมต่ออยู่ให้โดยอัตโนมัติ ป้อนรหัสผ่านเพียงครั้งเดียว คิวอาร์โค้ด Wi-Fi มาตรฐาน (WIFI:S:…;T:WPA;P:…;;) ก็พร้อมใช้ คนอื่นแค่เล็งกล้องในตัวของ iPhone หรือโทรศัพท์ Android ไปที่โค้ดก็เชื่อมต่อได้ทันที

📷

ถ่ายรูปแล้วเชื่อมต่อ

ถ่ายรูปป้าย Wi-Fi ในร้านกาแฟหรือที่พัก หรือเลือกรูปจากคลังรูปภาพ ระบบรู้จำข้อความบนอุปกรณ์จะกรอกชื่อเครือข่ายและรหัสผ่านให้ แตะ เชื่อมต่อ iPhone เครื่องนี้ แล้วคุณก็ออนไลน์ได้เลย

🖼️

สร้างป้าย Wi-Fi สำหรับแขก

ออกแบบป้าย Wi-Fi สำหรับร้านของคุณด้วยธีม 7 แบบ ใส่ชื่อร้านและโลโก้ เลือกแบบ การ์ดสำหรับหน้าจอและโซเชียลมีเดีย หรือโปสเตอร์ A4 แนวตั้งสำหรับพิมพ์ จากนั้นบันทึกเป็นรูปภาพ แชร์ หรือพิมพ์ทันทีด้วย AirPrint เก็บป้ายไว้ได้ไม่จำกัดจำนวน

🧩

วิดเจ็ตบนหน้าจอโฮม

วางคิวอาร์โค้ดของ Wi-Fi ที่ใช้บ่อยไว้ในวิดเจ็ตบนหน้าจอโฮม เมื่อแขกถาม ก็แค่ยื่นหน้าจอให้ดู ไม่ต้องเปิดแอปเลย

📍

สถานที่ที่ไปบ่อยขึ้นก่อน

MyFi จำได้ว่าคุณเชื่อมต่อหรือแชร์แต่ละเครือข่ายไว้ที่ไหน เมื่อคุณกลับไปที่เดิม เครือข่ายนั้นจะขึ้นไปอยู่บนสุดของรายการ และคุณยังดูสถานที่ที่บันทึกไว้บนแผนที่ได้ด้วย

📱

ฮอตสปอตก็มีคิวอาร์โค้ด

ฮอตสปอตส่วนบุคคลของ iPhone ปล่อยสัญญาณจากตัวเครื่องเอง จึงไม่สามารถเชื่อมต่อกับตัวเองได้ MyFi จึงแยกแสดงฮอตสปอตไว้ต่างหาก และสร้างคิวอาร์โค้ดไว้แชร์ให้คนอื่นแทนการพยายามเชื่อมต่อ

ข้อมูลของคุณอยู่บนอุปกรณ์ของคุณเท่านั้น

MyFi ไม่มีเซิร์ฟเวอร์ ชื่อและรหัสผ่าน Wi-Fi ข้อความที่อ่านจากรูปภาพ และตำแหน่งที่ตั้ง จะถูกประมวลผลและจัดเก็บ บนอุปกรณ์ของคุณเท่านั้น และจะไม่ถูกส่งไปที่ใดเลย ไม่มีโฆษณา ไม่มีการวิเคราะห์โดยบุคคลที่สาม และไม่มีการติดตาม มีเพียงสถิติการใช้งานแบบไม่ระบุตัวตนและรายงานข้อขัดข้องที่ส่งไปยัง Apple iCloud เพื่อนำไปพัฒนาแอปให้ดีขึ้น

ข้อควรทราบ

  • ด้วยเหตุผลด้านความปลอดภัย iOS ไม่อนุญาตให้แอปใดอ่านรหัสผ่าน Wi-Fi ที่จัดเก็บไว้ในอุปกรณ์ การแชร์จึงทำงานแบบ "ตรวจหาชื่อให้อัตโนมัติ ป้อนรหัสผ่านเพียงครั้งเดียว" หลังจากนั้น MyFi จะใช้รหัสผ่านที่บันทึกไว้
  • การเชื่อมต่อเครือข่ายต้องใช้ iPhone เครื่องจริง เครื่องจำลอง iOS (Simulator) ไม่สามารถเชื่อมต่อเครือข่าย Wi-Fi ได้
