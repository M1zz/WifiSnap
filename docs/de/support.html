Support / Hilfe

Brauchen Sie Hilfe mit MyFi?

So verwenden Sie MyFi

1. WLAN teilen

Das verbundene Netzwerk wird automatisch erkannt. Geben Sie das Passwort einmal ein und tippen Sie auf QR-Code erstellen. Wer die Kamera seines iPhone oder Android-Smartphones auf den Code richtet, ist verbunden, ohne das Passwort eintippen zu müssen.

2. Per Foto mit einem WLAN verbinden

Tippen Sie auf Kamera oder Mediathek und wählen Sie ein Foto eines WLAN-Aushangs. MyFi liest Netzwerkname und Passwort aus und trägt sie ein. Tippen Sie auf Dieses iPhone verbinden, um sich zu verbinden.

3. Gespeicherte Netzwerke wiederverwenden

Netzwerke, mit denen Sie sich verbinden oder die Sie teilen, werden automatisch gespeichert. Tippen Sie auf ein Netzwerk, um QR-Code und Details zu öffnen, streichen Sie nach rechts, um sich zu verbinden, oder nach links, um den QR-Code zu teilen. Halten Sie ein Netzwerk gedrückt, um einen Gäste-Aushang zu erstellen oder es zu löschen.

Häufige Fragen

Können andere mein WLAN-Passwort sehen?

Der QR-Code enthält die üblichen WLAN-Zugangsdaten. Nutzen können ihn nur die Personen, mit denen Sie ihn teilen, und ob Sie ihn teilen, entscheiden immer Sie.

Warum muss ich das Passwort eingeben?

Aus Sicherheitsgründen erlaubt iOS keiner App, die auf dem Gerät gespeicherten WLAN-Passwörter auszulesen. Deshalb geben Sie das Passwort beim Teilen eines Netzwerks einmal ein. Danach ist es gespeichert und jederzeit wieder verfügbar.

Im Simulator funktioniert das Verbinden nicht.

Das Verbinden mit WLANs funktioniert nur auf einem echten iPhone. Der iOS-Simulator unterstützt das nicht.

Name oder Passwort auf meinem Foto wurden falsch erkannt.

Gehen Sie näher heran und nehmen Sie ein schärferes Foto auf, um bessere Ergebnisse zu erzielen. Name und Passwort können Sie vor dem Verbinden jederzeit korrigieren.
