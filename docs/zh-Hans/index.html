MyFi

轻松分享和连接 Wi-Fi

不用再一个字母一个字母地报密码，一张二维码就搞定。

查看功能 GitHub

iOS 17.0 或更高版本 · iPhone

为这些时刻而生

你把 Wi-Fi 密码念给客人听，对方却输错了；你照着咖啡馆墙上的提示牌抄密码，结果错了一个字母； 同一个密码，你解释了一遍又一遍。有了 MyFi，这一切只需一张二维码、一张照片。

功能

🔗

用二维码分享 Wi-Fi

MyFi 会自动识别你当前连接的网络名称。只需输入一次密码，就能生成标准 Wi-Fi 二维码 （WIFI:S:…;T:WPA;P:…;;）。对方只要用 iPhone 或安卓手机的系统相机对准它即可连接。

📷

拍一下就能连

拍下咖啡馆或民宿里的 Wi-Fi 提示牌，或从相册中选一张照片。 设备端文字识别会自动填好网络名称和密码。轻点连接此 iPhone，马上就能上网。

🖼️

制作访客 Wi-Fi 提示牌

提供7 种主题，为你的店铺设计 Wi-Fi 提示牌。加上店名和标志，可选择适合屏幕和社交媒体的 卡片，或适合打印的竖版 A4 海报， 然后存为图片、分享出去，或直接通过 AirPrint 打印。提示牌数量不限，想存多少就存多少。

🧩

主屏幕小组件

把常用 Wi-Fi 的二维码放到主屏幕小组件上。 客人问起时，亮出屏幕就行，连 App 都不用打开。

📍

常去的地方优先显示

MyFi 会记住你在哪里连接或分享过每个网络。当你回到同一个地方时， 该网络会排到列表最前面。你还可以在地图上查看已保存的地点。

📱

个人热点也能生成二维码

iPhone 的个人热点就是由这台手机自己发出的，所以它无法连接自己的热点。 MyFi 会单独标记热点，不去尝试连接，而是生成一张可以分享给他人的二维码。

数据只保存在你的设备上

MyFi 没有服务器。Wi-Fi 名称和密码、从照片中识别出的文字以及位置信息， 都只在你的设备上处理和存储，绝不会发送到任何地方。 没有广告，没有第三方分析，也没有追踪。为了改进 App，仅会向 Apple iCloud 发送匿名使用统计和崩溃报告。

使用须知

  • 出于安全考虑，iOS 不允许任何 App 读取设备上存储的 Wi-Fi 密码。 因此分享时采用“自动识别名称，密码只需输入一次”的方式。之后，MyFi 会直接使用已保存的密码。
  • 连接网络需要使用真实的 iPhone。iOS 模拟器无法连接 Wi-Fi 网络。
