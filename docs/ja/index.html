Wi-Fiをもっと手軽に共有・接続

パスワードを一文字ずつ伝える必要はもうありません。QRコードひとつで完了です。

機能を見る GitHub

iOS 17.0以降 · iPhone

こんなとき、ありませんか

来客にWi-Fiのパスワードを読み上げたのに、入力ミスでつながらない。カフェの壁に貼られたパスワードを書き写したら、一文字だけ間違えていた。 同じパスワードを何度も説明している。MyFiなら、そのすべてがQRコードひとつ、写真1枚で片付きます。

主な機能

🔗

Wi-FiをQRコードで共有

接続中のネットワーク名をMyFiが自動で取得します。パスワードを一度入力するだけで、標準形式のWi-Fi QRコード （WIFI:S:…;T:WPA;P:…;;）が完成。相手はiPhoneやAndroidの標準カメラをかざすだけで接続できます。

📷

撮るだけで接続

カフェや宿泊先に貼られたWi-Fi案内を撮影するか、写真ライブラリから画像を選びます。 デバイス上の文字認識がネットワーク名とパスワードを自動入力。このiPhoneを接続をタップすれば、すぐにインターネットにつながります。

🖼️

ゲストWi-Fiの案内ボードを作成

7種類のテーマから、お店用のWi-Fi案内ボードをデザインできます。店名やロゴを入れ、画面表示やSNS向けの カードか、印刷向けの縦型A4ポスターを選択。 画像として保存・共有するほか、AirPrintでそのまま印刷することもできます。案内ボードはいくつでも保存できます。

🧩

ホーム画面ウィジェット

よく使うWi-FiのQRコードをホーム画面のウィジェットに置いておけます。 来客に聞かれたら、画面を見せるだけ。アプリを開く必要もありません。

📍

よく行く場所のWi-Fiを優先表示

MyFiは、各ネットワークに接続・共有した場所を記憶します。同じ場所に戻ってくると、 そのネットワークがリストの一番上に表示されます。保存した場所は地図でも確認できます。

📱

インターネット共有にもQRコード

iPhoneのインターネット共有はそのiPhone自身が発信しているため、同じiPhoneから接続することはできません。 MyFiはインターネット共有を区別して表示し、接続を試みる代わりに相手に見せるためのQRコードを作成します。

データはお使いのデバイスの中だけに

MyFiにはサーバがありません。Wi-Fiの名前やパスワード、写真から読み取った文字、位置情報は すべてデバイス上でのみ処理・保存され、外部に送信されることはありません。 広告、第三者による解析、トラッキングも一切ありません。アプリの改善のため、匿名の利用統計とクラッシュレポートのみをApple iCloudに送信します。

ご利用にあたって

  • セキュリティ上の理由から、iOSではどのアプリもデバイスに保存されたWi-Fiパスワードを読み取ることができません。 そのため共有は「ネットワーク名は自動取得、パスワードは最初に一度だけ入力」という流れになります。2回目以降は、保存したパスワードを使用します。
  • ネットワークへの接続には実機のiPhoneが必要です。iOSシミュレータではWi-Fiに接続できません。
