MyFi

輕鬆分享與連線 Wi-Fi

不必再一個字一個字唸密碼，一張 QR Code 就搞定。

查看功能 GitHub

iOS 17.0 或以上版本 · iPhone

專為這些時刻而設計

你把 Wi-Fi 密碼唸給客人聽，對方卻輸入錯誤；你照著咖啡廳牆上的告示牌抄密碼，結果錯了一個字母； 同一組密碼，你解釋了一次又一次。有了 MyFi，這一切只需要一張 QR Code、一張照片。

功能

🔗

用 QR Code 分享 Wi-Fi

MyFi 會自動偵測你目前連線的網路名稱。只要輸入一次密碼，就能產生標準的 Wi-Fi QR Code （WIFI:S:…;T:WPA;P:…;;）。對方只需用 iPhone 或 Android 手機的內建相機對準即可連線。

📷

拍一下就能連線

拍下咖啡廳或民宿的 Wi-Fi 告示牌，或從圖庫中挑選一張照片。 裝置上的文字辨識會自動填入網路名稱和密碼。點一下連線此 iPhone，馬上就能上網。

🖼️

製作訪客 Wi-Fi 告示牌

提供 7 種主題，為你的店家設計 Wi-Fi 告示牌。加上店名和標誌，可選擇適合螢幕與社群媒體的 卡片，或適合列印的直式 A4 海報， 接著儲存成圖片、分享出去，或直接用 AirPrint 列印。告示牌數量不限，想存幾張都可以。

🧩

主畫面小工具

把常用 Wi-Fi 的 QR Code 放到主畫面小工具上。 客人問起時，秀出螢幕就好，連 App 都不用打開。

📍

常去的地方優先顯示

MyFi 會記住你在哪裡連線或分享過每個網路。當你回到同一個地方， 該網路就會排到列表最上方。你也可以在地圖上查看已儲存的地點。

📱

個人熱點也能產生 QR Code

iPhone 的個人熱點是由這支手機本身發出的，因此無法連線到自己的熱點。 MyFi 會另外標示熱點，不會嘗試連線，而是產生一張可分享給他人的 QR Code。

資料只存在你的裝置上

MyFi 沒有伺服器。Wi-Fi 名稱與密碼、從照片辨識出的文字以及位置資訊， 都只在你的裝置上處理與儲存，絕不會傳送到任何地方。 沒有廣告、沒有第三方分析，也沒有追蹤。為了改善 App，僅會將匿名使用統計與當機報告傳送至 Apple iCloud。

使用須知

  • 基於安全考量，iOS 不允許任何 App 讀取裝置上儲存的 Wi-Fi 密碼。 因此分享時採用「自動偵測名稱，密碼只需輸入一次」的方式。之後，MyFi 會直接使用已儲存的密碼。
  • 連線網路需要使用實體 iPhone。iOS 模擬器無法連線 Wi-Fi 網路。
