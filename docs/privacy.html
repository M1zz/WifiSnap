개인정보 처리방침

마이파이 (iOS) · 최종 업데이트: 2026년 8월 17일

한 줄 요약

마이파이는 어떤 개인정보도 수집·전송·판매하지 않습니다. 앱에는 서버가 없고, 모든 데이터는 사용자의 기기 안에서만 처리·저장됩니다. 광고·분석·추적(SDK, 쿠키, 식별자) 도구를 일절 사용하지 않으며, 회원가입이나 로그인도 없습니다.

1. 앱이 사용하는 권한

카메라 선택

와이파이 안내문을 촬영해 아이디(SSID)와 비밀번호를 인식(OCR)하기 위해 사용합니다. 이미지 분석은 애플의 Vision 프레임워크로 전적으로 기기 안에서(on-device) 이뤄지며, 촬영한 사진과 인식 결과는 외부로 전송되지 않습니다. 촬영본은 인식에만 쓰이고 앱이 따로 보관하지 않습니다.

사진 선택

앨범에 있는 와이파이 안내문 사진을 골라 인식하거나, 안내판에 넣을 매장 로고 이미지를 고를 때 사용합니다. 앱은 사용자가 직접 고른 사진에만 접근하며, 사진 라이브러리 전체를 읽거나 어떤 이미지도 외부로 보내지 않습니다.

위치 선택

두 가지 목적으로만 사용합니다.

  • iOS에서 현재 연결된 와이파이 이름(SSID)을 확인하려면 위치 권한이 필요합니다(애플의 정책입니다).
  • 연결·공유한 와이파이의 좌표를 함께 기억해 두었다가, 같은 장소에 다시 오면 그 와이파이를 목록 위로 올려 줍니다(지도 표시 포함).

위치는 앱을 사용하는 동안에만 확인하며, 백그라운드 추적이나 이동 경로 수집은 하지 않습니다. 좌표는 해당 와이파이 항목과 함께 기기에만 저장되고 외부로 전송되지 않습니다.

위 권한은 모두 선택 사항입니다. 거부해도 QR 만들기·안내판 만들기 등 대부분의 기능은 그대로 쓸 수 있으며, 해당 권한이 필요한 기능만 동작하지 않습니다. 권한은 언제든 iOS 설정 → 마이파이에서 변경할 수 있습니다.

2. 기기에 저장되는 정보

다음 정보가 사용자의 기기에만 저장됩니다. 모두 사용자가 직접 입력하거나 저장한 것입니다.

  • 와이파이 이름(SSID)과 비밀번호 — 저장·연결·공유한 항목
  • 저장 시각과 좌표 — 근처 와이파이 추천·지도 표시용(위치 권한을 허용한 경우)
  • 안내판 설정 — 매장 이름, 문구, 테마·레이아웃 선택, 로고 이미지
  • 사용자가 알려준 와이파이 이름 목록 — 설정 화면 캡처에서 가져오거나 직접 적어 넣은 이름(비밀번호는 포함하지 않습니다)

저장에는 iOS의 로컬 저장소(UserDefaults)를 사용하며, 홈 화면 위젯이 같은 목록을 보여 주기 위해 앱과 위젯이 공유하는 App Group 저장 영역(group.com.leeo.wifisnap)을 함께 사용합니다. 이 영역은 기기 안에 있으며, 다른 앱은 접근할 수 없습니다.

참고: 이 데이터는 기기 백업(iCloud 백업, 아이튠즈/파인더 백업)에 포함될 수 있습니다. 백업은 애플이 제공하는 기능으로 애플의 개인정보 처리방침을 따르며, 개발자는 백업 내용에 접근할 수 없습니다.

3. 제3자 제공 및 네트워크 통신

마이파이는 자체 서버를 운영하지 않으며, 어떤 데이터도 개발자나 제3자에게 전송하지 않습니다. 외부 분석·광고·크래시 리포트 SDK를 포함하지 않습니다.

사용자가 만든 QR 이미지나 안내판 이미지는 사용자가 직접 공유·인쇄 버튼을 눌렀을 때만 iOS의 표준 공유 시트를 통해 사용자가 선택한 상대·앱·프린터로 전달됩니다. 이때 어디로 보낼지는 전적으로 사용자가 결정합니다.

4. 데이터 보관과 삭제

저장된 정보는 사용자가 지우기 전까지 기기에 남아 있습니다. 삭제 방법은 다음과 같습니다.

  • 저장된 와이파이 — 목록에서 왼쪽으로 밀어 삭제
  • 안내판 — 안내판 목록에서 삭제
  • 전체 삭제 — 앱을 삭제하면 위젯 공유 영역을 포함해 기기에 저장된 관련 데이터가 모두 함께 제거됩니다

개발자가 보관하는 사용자 데이터가 없으므로, 별도의 삭제 요청 절차는 필요하지 않습니다.

5. 아동의 개인정보

마이파이는 아동을 대상으로 하지 않으며, 연령과 무관하게 어떤 개인정보도 수집하지 않습니다.

6. 보안

데이터가 기기를 떠나지 않으므로 전송 중 유출 위험이 없습니다. 다만 와이파이 비밀번호는 현재 iOS 로컬 저장소(UserDefaults)에 저장되며, 기기 잠금(암호·Face ID)과 iOS의 앱 샌드박스가 기본 보호 수단입니다. 기기를 다른 사람과 함께 쓰는 등 민감한 환경이라면 저장 대신 필요할 때 입력해 사용하시길 권합니다.

7. 방침 변경

이 방침이 바뀌면 이 페이지의 내용과 상단의 최종 업데이트 날짜를 갱신합니다. 수집 항목이 생기는 등 중요한 변경이 있을 경우 앱 업데이트 설명을 통해 함께 안내합니다.
