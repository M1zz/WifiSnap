Precisa de ajuda com o MyFi?

Como usar o MyFi

1. Compartilhe seu Wi-Fi

A rede em que você está conectado é detectada automaticamente. Digite a senha uma única vez e toque em Criar QR. Qualquer pessoa pode se conectar sem digitar a senha, basta apontar a câmera do iPhone ou do celular Android para o código.

2. Conecte-se ao Wi-Fi por uma foto

Toque em Câmera ou Galeria e escolha a foto de uma placa de Wi-Fi. O MyFi lê o nome da rede e a senha e preenche tudo para você. Toque em Conectar este iPhone para se conectar.

3. Reutilize as redes salvas

As redes às quais você se conecta ou que compartilha são salvas automaticamente. Toque em uma rede para abrir o QR code e os detalhes, deslize para a direita para se conectar ou para a esquerda para compartilhar o QR code. Mantenha o dedo sobre uma rede para criar uma placa para visitantes ou excluí-la.

Perguntas frequentes

Outras pessoas podem ver a senha do meu Wi-Fi?

O QR code contém os dados de acesso ao Wi-Fi no formato padrão. Só as pessoas com quem você compartilhar podem usá-lo, e é sempre você quem decide se vai compartilhar.

Por que preciso digitar a senha?

Por motivos de segurança, o iOS não permite que nenhum app leia as senhas de Wi-Fi salvas no aparelho. Por isso você digita a senha uma única vez ao compartilhar uma rede. Depois ela fica salva e pronta para usar de novo.

A conexão não funciona no simulador.

A conexão a redes Wi-Fi só funciona em um iPhone de verdade. O simulador do iOS não oferece suporte a isso.

O nome ou a senha da minha foto foram lidos errado.

Chegue mais perto e tire uma foto mais nítida para ter um resultado melhor. Você sempre pode corrigir o nome e a senha antes de se conectar.
