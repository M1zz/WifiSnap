Assistance / Aide

Besoin d’un coup de main avec MyFi ?

Utiliser MyFi

1. Partager votre Wi-Fi

Le réseau auquel vous êtes connecté est détecté automatiquement. Saisissez le mot de passe une seule fois, puis touchez Créer le QR code. N’importe qui peut alors se connecter sans taper le mot de passe, simplement en visant le code avec l’appareil photo de son iPhone ou de son téléphone Android.

2. Rejoindre un Wi-Fi à partir d’une photo

Touchez Photo ou Photothèque et choisissez la photo d’une affichette Wi-Fi. MyFi lit le nom du réseau et le mot de passe, puis les remplit pour vous. Touchez Connecter cet iPhone pour vous connecter.

3. Réutiliser les réseaux enregistrés

Les réseaux que vous rejoignez ou partagez sont enregistrés automatiquement. Touchez un réseau pour afficher son QR code et ses détails, balayez vers la droite pour le rejoindre, ou vers la gauche pour partager son QR code. Maintenez le doigt sur un réseau pour créer une affichette pour vos invités ou le supprimer.

Questions fréquentes

D’autres personnes peuvent-elles voir mon mot de passe Wi-Fi ?

Le QR code contient les informations de connexion Wi-Fi au format standard. Seules les personnes avec qui vous le partagez peuvent l’utiliser, et c’est toujours vous qui décidez de le partager ou non.

Pourquoi dois-je saisir le mot de passe ?

Pour des raisons de sécurité, iOS n’autorise aucune app à lire les mots de passe Wi-Fi enregistrés sur l’appareil. Vous saisissez donc le mot de passe une seule fois lorsque vous partagez un réseau. Il est ensuite enregistré et prêt à être réutilisé.

La connexion ne fonctionne pas dans le simulateur.

La connexion aux réseaux Wi-Fi ne fonctionne que sur un véritable iPhone. Le simulateur iOS ne la prend pas en charge.

Le nom ou le mot de passe de ma photo a été mal lu.

Rapprochez-vous et prenez une photo plus nette pour un meilleur résultat. Vous pouvez toujours corriger le nom et le mot de passe avant de vous connecter.
